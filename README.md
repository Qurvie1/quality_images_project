# Image Quality Sorter

![tests](docs/_static/badges/tests.svg)
![coverage](docs/_static/badges/coverage.svg)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

`image-quality-sorter` ranks images by sharpness and blur. The default metric is
**variance of Laplacian**: a grayscale image is convolved with a Laplacian kernel,
and the variance of that response is used as the focus score. Higher score usually
means sharper edges and better focus. A second metric, **Tenengrad**, is included
for comparison.

The repository is intentionally structured like a hypermodern Python coursework
project: `src/`, `tests/`, `docs/`, `pyproject.toml`, `uv`, Ruff, pytest, mypy,
Poe the Poet, Sphinx, CI, performance report, TestPyPI instructions, and a
standalone build target.

## Installation

```bash
uv sync --all-groups
```

Run the CLI:

```bash
uv run iqsort examples/sample_input --dry-run
```

Sort images and copy them to an output directory:

```bash
uv run iqsort examples/sample_input --output-dir sorted --csv results.csv
```

## Example input-output

Input directory:

```text
examples/sample_input/
├── blur.png
├── medium.png
└── sharp.png
```

Command:

```bash
uv run iqsort examples/sample_input --dry-run --threshold 100
```

Typical output:

```text
rank  label   score       image
1     sharp   1021490.82  examples/sample_input/sharp.png
2     blurry  15.91       examples/sample_input/medium.png
3     blurry  8.74        examples/sample_input/blur.png
```

Exact scores can differ by image size and preprocessing. The threshold is a
project parameter, not a universal truth: pick it on your own dataset.


## CLI options

```bash
uv run iqsort --help
```

Important options:

- `--metric laplacian-variance|tenengrad` chooses the focus measure.
- `--recursive` scans nested directories.
- `--threshold FLOAT` changes the sharp/blurry label boundary.
- `--ascending` puts low-quality images first; default is high-quality first.
- `--output-dir DIR` copies ranked images using rank-prefixed filenames.
- `--csv FILE` writes machine-readable results.
- `--skip-errors` continues when a file has an image extension but cannot be read.

## Packaging and publishing

Build distributions:

```bash
uv run poe build
```

Upload to TestPyPI after configuring credentials:

```bash
uv run poe publish-testpypi
```

Build a standalone executable:

```bash
uv run poe standalone
```

For a GitHub release, run the standalone workflow on a tag and attach the file from
`dist/iqsort` or `dist/iqsort.exe` together with the source archives generated by
`uv build`.

## Performance report

Regenerate the benchmark figure:

```bash
uv run poe report-figures
```

Then compile `report/report.tex` with LaTeX. The document explains the benchmark,
uses synthetic images, and includes `report/figures/performance.png` generated by
Python.
